# YouTube Transcript Extractor

유튜브 링크를 붙여넣으면 영상의 대사를 텍스트로 뽑아주는 Mac용 도구입니다.
터미널 명령어를 몰라도 **더블클릭 → 브라우저 화면**으로 사용할 수 있습니다.

- 유튜브 자막(자동 생성 자막 포함)을 1~2초 만에 텍스트로 추출
- 복사 / `.txt`·`.md` 다운로드 / 시간 표시(`[01:23]`) 지원
- 요점정리 결과를 영상 정보와 합쳐 **마크다운 노트(.md)** 로 저장
- **요점정리용 복사** 버튼 → Claude·ChatGPT 등에 붙여넣으면 바로 요약
- **고정밀 모드**(선택): 자동 자막이 부정확할 때 음성을 직접 받아쓰기 (Apple Silicon Mac 전용)

> 모든 처리는 내 컴퓨터 안에서 이루어집니다. 화면은 `127.0.0.1`(내 컴퓨터)에서만 열리며 외부에서 접속할 수 없습니다.

## 설치

### 1. Python 준비

1. **터미널**을 엽니다. (`Cmd + Space` → "터미널" 입력 → Enter)
2. 아래 명령어를 붙여넣고 Enter:

   ```bash
   python3 --version
   ```

3. 결과에 따라:
   - `Python 3.9.x` 이상이 나오면 → 준비 완료. [2단계](#2-다운로드)로 가세요.
   - **"명령어 라인 개발자 도구를 설치하겠습니까?"** 창이 뜨면 → **설치**를 누르고 끝날 때까지 기다린 뒤, 위 명령어를 다시 실행해 버전을 확인하세요.
   - 그래도 안 되면 → [python.org/downloads](https://www.python.org/downloads/) 에서 macOS용 설치 파일을 받아 설치하세요.

### 2. 다운로드

**방법 A. 압축 파일로 받기 (추천)**

1. 이 저장소의 [**Releases**](../../releases/latest) 페이지로 이동합니다.
2. **Assets** 아래의 `Source code (zip)`을 눌러 내려받습니다.
3. 내려받은 zip 파일을 더블클릭해 압축을 풉니다.
4. 풀린 폴더를 원하는 곳(예: `문서` 폴더)으로 옮깁니다.

**방법 B. git으로 받기**

```bash
git clone https://github.com/wnsrud2002/youtube-transcript-extractor.git
```

### 3. 처음 실행

1. 폴더 안의 **`실행.command`** 를 더블클릭합니다.
2. **"열 수 없습니다" / "확인되지 않은 개발자"** 같은 경고가 뜨며 실행이 막히면 → 아래 [보안 경고 해결](#열-수-없습니다-보안-경고-해결)을 따라 하세요. (처음 한 번만 하면 됩니다)
3. 터미널 창이 열리고 `처음 실행: 필요한 프로그램을 설치합니다...` 가 표시됩니다. 1분 정도 기다리세요.
4. 설치가 끝나면 **브라우저가 자동으로 열리며** 화면이 나타납니다.

두 번째부터는 `실행.command` 더블클릭만 하면 바로 열립니다.

### "열 수 없습니다" 보안 경고 해결

zip으로 받은 뒤 `실행.command`를 더블클릭하면 아래와 비슷한 경고가 뜨고 실행되지 않을 수 있습니다.

> "실행.command"은(는) 확인되지 않은 개발자가 배포했기 때문에 열 수 없습니다.
>
> "실행.command"을(를) 열 수 없습니다. Apple은 이 항목에 악성 코드가 없음을 확인할 수 없습니다.

**왜 뜨나요?** macOS는 인터넷에서 받은 프로그램 중 Apple 인증(유료 개발자 서명)을 받지 않은 것을 기본으로 막습니다. 이 프로그램은 개인이 만든 무료 오픈소스라 Apple 인증을 받지 않았을 뿐, 고장이나 바이러스를 뜻하는 경고는 아닙니다. 내용이 걱정되면 [아래](#무엇을-실행하나요)에서 실행 파일이 하는 일을 확인할 수 있습니다.

아래 방법 중 **하나만** 하면 됩니다.

#### 방법 1. 터미널 한 줄로 해결 (추천 · 모든 macOS 버전)

`실행.command`와 `고정밀모드 설치.command`를 한 번에 풀어주는 가장 확실한 방법입니다.

1. **터미널**을 엽니다. (`Cmd + Space` → "터미널" 입력 → Enter)
2. 아래 문구를 복사해 터미널에 붙여넣습니다. **아직 Enter를 누르지 마세요.** (끝에 띄어쓰기 한 칸이 포함되어 있습니다)

   ```
   xattr -dr com.apple.quarantine 
   ```

3. Finder에서 **압축을 푼 폴더**(`youtube-transcript-extractor-...`)를 **터미널 창 안으로 끌어다 놓습니다.** 폴더 경로가 자동으로 입력됩니다.

   ```
   xattr -dr com.apple.quarantine /Users/내이름/Downloads/youtube-transcript-extractor-1.1.0
   ```

4. **Enter**를 누릅니다. 아무 메시지도 나오지 않으면 성공입니다.
5. 이제 `실행.command`를 더블클릭하면 경고 없이 실행됩니다.

> `xattr -dr com.apple.quarantine`: 폴더 안 모든 파일에서 "인터넷에서 받은 파일" 표시를 지우는 명령어입니다. 이 폴더에만 적용되며 Mac 전체 보안 설정은 바뀌지 않습니다.

#### 방법 2. 시스템 설정에서 허용 (macOS 15 Sequoia 이상)

1. `실행.command`를 더블클릭 → 경고 창이 뜨면 **완료**(또는 **확인**)를 눌러 닫습니다. (**휴지통으로 이동**은 누르지 마세요)
2. 화면 왼쪽 위  메뉴 → **시스템 설정** → 왼쪽 목록에서 **개인정보 보호 및 보안**을 누릅니다.
3. 오른쪽을 맨 아래 **보안** 부분까지 내리면 `"실행.command"이(가) 차단되었습니다`와 비슷한 문구와 **그래도 열기** 버튼이 있습니다. **그래도 열기**를 누릅니다.
   - 이 문구는 경고가 뜬 뒤 **약 1시간 동안만** 표시됩니다. 보이지 않으면 1번부터 다시 하세요.
4. Mac 암호(또는 Touch ID)를 입력합니다.
5. `실행.command`를 다시 더블클릭 → 확인 창에서 **열기**를 누릅니다.
6. 고정밀 모드를 설치할 때 `고정밀모드 설치.command`도 같은 과정을 한 번 더 거쳐야 합니다.

#### 방법 3. 우클릭으로 열기 (macOS 14 Sonoma 이하)

1. `실행.command`를 **우클릭**(또는 `Control` 누른 채 클릭) → **열기**
2. 경고 창에 **열기** 버튼이 생깁니다. **열기**를 누릅니다.

> macOS 15 이상에서는 이 방법이 막혔습니다. 방법 1이나 방법 2를 사용하세요.

#### 그 밖에 뜰 수 있는 창

| 창 | 누를 것 |
|---|---|
| "터미널"이(가) "다운로드" 폴더(또는 "문서", "데스크탑")의 파일에 접근하려고 합니다 | **허용** — 프로그램 폴더를 읽기 위해 필요합니다 |
| 명령어 라인 개발자 도구를 설치하겠습니까? | **설치** — Python이 없을 때 뜹니다. [1. Python 준비](#1-python-준비) 참고 |

#### git으로 받으면 이 경고가 뜨지 않습니다

[방법 B (git clone)](#2-다운로드)로 받은 파일에는 "인터넷에서 받은 파일" 표시가 붙지 않아 경고 없이 바로 실행됩니다.

#### 하지 마세요

인터넷에 있는 `sudo spctl --master-disable`(Mac 전체 보안 검사 끄기) 방법은 **권장하지 않습니다.** 다른 모든 프로그램에 대한 보호까지 꺼집니다. 위 방법 1은 이 폴더에만 적용되므로 더 안전합니다.

#### 무엇을 실행하나요?

`.command` 파일은 텍스트 파일이라 텍스트 편집기로 열어 내용을 직접 볼 수 있습니다.

- **`실행.command`**: Python 버전 확인 → 처음이면 이 폴더 안에 `.venv`를 만들고 필요한 라이브러리(`requirements.txt`)를 설치 → 내 컴퓨터(`127.0.0.1`)에서만 접속되는 화면 서버를 켜고 브라우저를 엽니다.
- **`고정밀모드 설치.command`**: Apple Silicon인지 확인 → `requirements-whisper.txt`의 라이브러리를 `.venv`에 설치합니다.

설치되는 파일은 모두 이 폴더 안(`.venv`)에 들어가며, 폴더를 지우면 함께 사라집니다. (고정밀 모드의 음성 인식 모델만 예외 — [삭제](#업데이트--삭제) 참고)

## 사용법

### 기본 사용

1. `실행.command`를 더블클릭합니다. 브라우저가 열립니다.
2. 유튜브 링크를 입력칸에 붙여넣고 **텍스트 추출**을 누릅니다.
3. 결과가 아래에 표시됩니다.

지원하는 링크 형식:

```
https://www.youtube.com/watch?v=XXXXXXXXXXX
https://youtu.be/XXXXXXXXXXX
https://www.youtube.com/shorts/XXXXXXXXXXX
https://www.youtube.com/live/XXXXXXXXXXX
https://www.youtube.com/embed/XXXXXXXXXXX
재생목록 안의 영상 링크 (&list=... 가 붙어 있어도 됨)
```

### 옵션

| 옵션 | 설명 |
|---|---|
| **시간 표시** | 각 줄 앞에 `[01:23]` 형식의 재생 시간을 붙입니다. |
| **언어** | 자막이 여러 언어일 때 어느 언어를 먼저 가져올지 고릅니다. (한국어 / 영어 / 일본어 우선) |
| **고정밀 모드** | 자막 대신 음성을 직접 받아씁니다. [별도 설치 필요](#고정밀-모드-선택) |

자막 선택 순서: 사람이 직접 올린 자막 → 자동 생성 자막 순으로, 각각 선택한 언어 순서대로 찾습니다. 원하는 언어가 없으면 있는 자막 중 하나를 가져옵니다.

### 결과 활용 버튼

| 버튼 | 동작 |
|---|---|
| **복사** | 추출한 텍스트를 클립보드에 복사 |
| **.txt 다운로드** | 텍스트 파일로 저장 (파일명: 영상 제목) |
| **.md 다운로드** | 마크다운 파일로 저장 — 제목·채널·링크 포함, [아래 설명](#md-파일-형식) 참고 |
| **요점정리용 복사** | "요점정리해줘" 요청문 + 전체 텍스트를 한 번에 복사 |
| **Claude 열기 ↗** | 새 탭으로 claude.ai 열기 |

### 요점정리 받기

1. **요점정리용 복사**를 누릅니다.
2. **Claude 열기 ↗**를 누르거나, ChatGPT·Gemini 등 원하는 AI 채팅을 엽니다.
3. 입력창에 `Cmd + V`로 붙여넣고 전송합니다.

핵심 요약 3줄 → 주제별 요점 → 중요 용어·숫자 정리 형식의 **마크다운**으로 답변을 받습니다.
API 키나 별도 비용은 필요 없고, 사용하는 AI 서비스의 요금제(무료 포함) 안에서 동작합니다.

### 요점정리를 .md 파일로 저장

1. AI 답변 아래의 **복사 버튼**을 누릅니다. (Claude·ChatGPT의 복사 버튼은 마크다운 원문 그대로 복사합니다)
2. 앱 화면 맨 아래 **요점정리 .md로 저장** 칸에 붙여넣습니다.
3. **전체 대사도 함께 저장**을 켜거나 끄고, **요약 .md 다운로드**를 누릅니다.

`영상 제목 - 요점정리.md` 파일이 저장됩니다. 구성:

```markdown
# 영상 제목

- 영상: https://youtu.be/...
- 채널: 채널명
- 출처: ko 자동생성 자막
- 추출일: 2026-09-28

---

## 요점정리

### 핵심 요약 (3줄)
...

---

## 전체 대사          ← "전체 대사도 함께 저장"을 켰을 때만

...
```

### .md 파일 형식

**.md 다운로드**로 받은 파일은 옵시디언·노션·타이포라 등 마크다운 앱이나 GitHub에서 서식대로 보입니다.

- 맨 위에 영상 제목, 채널, 링크, 자막 출처, 추출일이 들어갑니다.
- **시간 표시를 켠 경우**: 줄마다 `- [01:23](영상 링크)` 형식이라, 시간을 누르면 유튜브의 해당 장면으로 이동합니다.
- **시간 표시를 끈 경우**: 영상 1분 단위로 문단을 나눠 읽기 좋게 정리합니다.
- 영상 제목을 가져오지 못하면 제목 자리에 `YouTube 영상 (영상 ID)`가 들어갑니다. 대사 추출에는 영향이 없습니다.

### 종료

`실행.command`를 실행할 때 열린 **터미널 창을 닫으면** 종료됩니다.

## 고정밀 모드 (선택)

유튜브 자동 자막은 문장부호가 없고 단어를 잘못 알아듣는 경우가 많습니다.
고정밀 모드는 영상의 음성을 내려받아 OpenAI의 음성 인식 모델 **Whisper**로 내 컴퓨터에서 직접 받아씁니다.

36분 한국어 강의로 비교한 결과:

| | 유튜브 자동 자막 | 고정밀 모드 |
|---|---|---|
| 문장부호 | 0개 | 420개 |
| 잘못 인식된 단어 | 곳곳에 있음 | 크게 줄어듦 |
| 걸린 시간 | 1~2초 | 약 2분 (첫 실행, 모델 다운로드 포함) |

### 설치

> Apple Silicon Mac 전용입니다. Intel Mac에서는 설치되지 않습니다.

1. 먼저 `실행.command`를 한 번 실행해 기본 설치를 마칩니다.
2. **`고정밀모드 설치.command`** 를 더블클릭합니다. (보안 경고가 뜨면 [처음 실행](#3-처음-실행)과 같은 방법으로 허용)
3. 수 분 기다리면 `설치 완료` 가 표시됩니다.

### 사용

화면에서 **고정밀 모드 (느림)** 를 체크하고 텍스트 추출을 누릅니다.

- **첫 사용 시** 음성 인식 모델(약 1.6GB)을 내려받으므로 더 오래 걸립니다.
- 처리 시간은 영상 길이에 비례합니다. 진행 중에는 버튼에 "받아쓰는 중"이 표시됩니다.
- 언어는 **언어** 선택의 첫 번째 언어로 받아씁니다. (예: "한국어 우선" → 한국어로 인식)

## 터미널에서 사용하기 (고급)

폴더 안에서 터미널을 열고:

```bash
.venv/bin/python yt_transcript.py "<유튜브 링크>"                  # 화면에 출력
.venv/bin/python yt_transcript.py "<링크>" -o 결과.txt              # 텍스트 파일로 저장
.venv/bin/python yt_transcript.py "<링크>" -o 결과.md               # 마크다운으로 저장 (확장자로 자동 판단)
.venv/bin/python yt_transcript.py "<링크>" --timestamps             # 시간 표시
.venv/bin/python yt_transcript.py "<링크>" --lang en,ko             # 언어 우선순위
.venv/bin/python yt_transcript.py "<링크>" --whisper                # 고정밀 모드
.venv/bin/python yt_transcript.py --help                            # 전체 옵션
```

`.venv`는 `실행.command`를 처음 실행할 때 만들어지는 이 프로그램 전용 Python 환경입니다.

## 문제 해결

<details>
<summary><b>"열 수 없습니다" / "확인되지 않은 개발자" / "악성 코드가 없음을 확인할 수 없습니다"</b></summary>

[⚠️ 보안 경고 해결](#열-수-없습니다-보안-경고-해결)을 따라 하세요. 어떤 macOS 버전이든 **방법 1(터미널 한 줄)** 이 가장 확실합니다.
</details>

<details>
<summary><b>"권한이 없기 때문에 열 수 없습니다"라고 나와요</b></summary>

실행 권한이 빠진 경우입니다. 터미널에서:

```bash
cd ~/Documents/youtube-transcript-extractor   # 실제 폴더 위치로
chmod +x *.command
```
</details>

<details>
<summary><b>"Python 3.9 이상이 필요합니다"라고 나와요</b></summary>

[1. Python 준비](#1-python-준비)를 진행한 뒤 다시 실행하세요.
</details>

<details>
<summary><b>"설치에 실패했습니다"라고 나와요</b></summary>

인터넷 연결을 확인하고 `실행.command`를 다시 실행하세요. 실패하면 자동으로 정리되므로 그냥 다시 실행하면 됩니다.
회사·학교 네트워크에서는 방화벽 때문에 설치가 막힐 수 있습니다.
</details>

<details>
<summary><b>브라우저가 자동으로 열리지 않아요</b></summary>

터미널 창에 표시된 `실행 중: http://127.0.0.1:XXXX` 주소를 복사해 브라우저 주소창에 붙여넣으세요.
주소 끝 번호는 실행할 때마다 달라질 수 있습니다. (기본 8765, 다른 프로그램이 쓰고 있으면 빈 번호로 바뀜)
</details>

<details>
<summary><b>"이 영상에는 자막이 없습니다" / "자막이 꺼져 있습니다"</b></summary>

영상 게시자가 자막을 막아둔 경우입니다. **고정밀 모드**를 사용하면 자막 없이도 받아쓸 수 있습니다.
</details>

<details>
<summary><b>"유튜브가 요청을 차단했습니다"</b></summary>

짧은 시간에 너무 많이 요청하면 유튜브가 일시적으로 막습니다. 잠시(수십 분~몇 시간) 기다린 뒤 다시 시도하세요.
VPN을 사용 중이라면 끄고 시도해 보세요.
</details>

<details>
<summary><b>잘 되던 게 갑자기 안 돼요</b></summary>

유튜브 쪽 변경으로 자막을 가져오는 방식이 깨졌을 수 있습니다. 폴더에서 터미널을 열고 라이브러리를 업데이트하세요:

```bash
.venv/bin/pip install -U youtube-transcript-api yt-dlp
```
</details>

<details>
<summary><b>"서버에 연결할 수 없습니다"라고 나와요</b></summary>

`실행.command`로 열린 터미널 창을 닫으면 서버도 꺼집니다. `실행.command`를 다시 실행하세요.
</details>

## 주의 사항

- 유튜브가 공식으로 제공하는 방법이 아닌 경로로 자막을 가져옵니다. 유튜브 정책 변경에 따라 동작하지 않을 수 있습니다.
- **개인 학습·참고 용도로만 사용하세요.** 추출한 텍스트를 재배포하거나 상업적으로 이용하면 원 영상의 저작권을 침해할 수 있습니다.
- 자동 생성 자막과 음성 인식 결과에는 오류가 있을 수 있습니다. 중요한 내용은 원본 영상으로 확인하세요.
