# YouTube Transcript Extractor

유튜브 링크를 붙여넣으면 영상의 대사를 텍스트로 뽑아주는 Mac용 도구입니다.
터미널 명령어를 몰라도 **더블클릭 → 브라우저 화면**으로 사용할 수 있습니다.

- 유튜브 자막(자동 생성 자막 포함)을 1~2초 만에 텍스트로 추출
- 복사 / `.txt` 다운로드 / 시간 표시(`[01:23]`) 지원
- **요점정리용 복사** 버튼 → Claude·ChatGPT 등에 붙여넣으면 바로 요약
- **고정밀 모드**(선택): 자동 자막이 부정확할 때 음성을 직접 받아쓰기 (Apple Silicon Mac 전용)

> 모든 처리는 내 컴퓨터 안에서 이루어집니다. 화면은 `127.0.0.1`(내 컴퓨터)에서만 열리며 외부에서 접속할 수 없습니다.

## 요구 사항

| 항목 | 기본 기능 | 고정밀 모드 |
|---|---|---|
| 운영체제 | macOS | macOS + **Apple Silicon**(M1/M2/M3/M4…) |
| Python | 3.9 이상 | 3.9 이상 |
| 저장 공간 | 약 50MB | 추가 약 3GB (프로그램 1.2GB + 음성 인식 모델 1.6GB) |

내 Mac이 Apple Silicon인지 확인: 화면 왼쪽 위  메뉴 → **이 Mac에 관하여** → "칩"에 `Apple M…`이 보이면 Apple Silicon입니다.

## 설치

### 1. Python 준비

1. **터미널**을 엽니다. (`Cmd + Space` → "터미널" 입력 → Enter)
2. 아래 명령어를 붙여넣고 Enter:

   ```bash
   python3 --version
   ```

3. 결과에 따라:
   - `Python 3.9.x` 이상이 나오면 → 준비 완료. [2단계](#2-다운로드)로 가세요.
   - **"명령어 라인 개발자 도구를 설치하겠습니까?"** 창이 뜨면 → **설치**를 누르고 끝날 때까지 기다린 뒤, 위 명령어를 다시 실행해 버전을 확인하세요.
   - 그래도 안 되면 → [python.org/downloads](https://www.python.org/downloads/) 에서 macOS용 설치 파일을 받아 설치하세요.

### 2. 다운로드

**방법 A. 압축 파일로 받기 (추천)**

1. 이 저장소의 [**Releases**](../../releases/latest) 페이지로 이동합니다.
2. **Assets** 아래의 `Source code (zip)`을 눌러 내려받습니다.
3. 내려받은 zip 파일을 더블클릭해 압축을 풉니다.
4. 풀린 폴더를 원하는 곳(예: `문서` 폴더)으로 옮깁니다.

**방법 B. git으로 받기**

```bash
git clone https://github.com/wnsrud2002/youtube-transcript-extractor.git
```

### 3. 처음 실행

1. 폴더 안의 **`실행.command`** 를 더블클릭합니다.
2. macOS가 **"확인되지 않은 개발자"** 경고를 띄우며 막을 수 있습니다. (인터넷에서 받은 파일에 대한 macOS 기본 보안 동작입니다)
   - **macOS 14 (Sonoma) 이하**: 파일을 **우클릭 → 열기 → 열기**
   - **macOS 15 (Sequoia) 이상**: 경고 창을 닫고 → **시스템 설정 → 개인정보 보호 및 보안** → 아래쪽의 "`실행.command`이(가) 차단되었습니다" 옆 **그래도 열기** → 다시 더블클릭
   - 이 과정은 처음 한 번만 하면 됩니다.
3. 터미널 창이 열리고 `처음 실행: 필요한 프로그램을 설치합니다...` 가 표시됩니다. 1분 정도 기다리세요.
4. 설치가 끝나면 **브라우저가 자동으로 열리며** 화면이 나타납니다.

두 번째부터는 `실행.command` 더블클릭만 하면 바로 열립니다.

## 사용법

### 기본 사용

1. `실행.command`를 더블클릭합니다. 브라우저가 열립니다.
2. 유튜브 링크를 입력칸에 붙여넣고 **텍스트 추출**을 누릅니다.
3. 결과가 아래에 표시됩니다.

지원하는 링크 형식:

```
https://www.youtube.com/watch?v=XXXXXXXXXXX
https://youtu.be/XXXXXXXXXXX
https://www.youtube.com/shorts/XXXXXXXXXXX
https://www.youtube.com/live/XXXXXXXXXXX
https://www.youtube.com/embed/XXXXXXXXXXX
재생목록 안의 영상 링크 (&list=... 가 붙어 있어도 됨)
```

### 옵션

| 옵션 | 설명 |
|---|---|
| **시간 표시** | 각 줄 앞에 `[01:23]` 형식의 재생 시간을 붙입니다. |
| **언어** | 자막이 여러 언어일 때 어느 언어를 먼저 가져올지 고릅니다. (한국어 / 영어 / 일본어 우선) |
| **고정밀 모드** | 자막 대신 음성을 직접 받아씁니다. [별도 설치 필요](#고정밀-모드-선택) |

자막 선택 순서: 사람이 직접 올린 자막 → 자동 생성 자막 순으로, 각각 선택한 언어 순서대로 찾습니다. 원하는 언어가 없으면 있는 자막 중 하나를 가져옵니다.

### 결과 활용 버튼

| 버튼 | 동작 |
|---|---|
| **복사** | 추출한 텍스트를 클립보드에 복사 |
| **.txt 다운로드** | 텍스트 파일로 저장 (파일명: 영상 ID) |
| **요점정리용 복사** | "요점정리해줘" 요청문 + 전체 텍스트를 한 번에 복사 |
| **Claude 열기 ↗** | 새 탭으로 claude.ai 열기 |

### 요점정리 받기

1. **요점정리용 복사**를 누릅니다.
2. **Claude 열기 ↗**를 누르거나, ChatGPT·Gemini 등 원하는 AI 채팅을 엽니다.
3. 입력창에 `Cmd + V`로 붙여넣고 전송합니다.

핵심 요약 3줄 → 주제별 요점 → 중요 용어·숫자 정리 형식으로 답변을 받습니다.
API 키나 별도 비용은 필요 없고, 사용하는 AI 서비스의 요금제(무료 포함) 안에서 동작합니다.

### 종료

`실행.command`를 실행할 때 열린 **터미널 창을 닫으면** 종료됩니다.

## 고정밀 모드 (선택)

유튜브 자동 자막은 문장부호가 없고 단어를 잘못 알아듣는 경우가 많습니다.
고정밀 모드는 영상의 음성을 내려받아 OpenAI의 음성 인식 모델 **Whisper**로 내 컴퓨터에서 직접 받아씁니다.

36분 한국어 강의로 비교한 결과:

| | 유튜브 자동 자막 | 고정밀 모드 |
|---|---|---|
| 문장부호 | 0개 | 420개 |
| 잘못 인식된 단어 | 곳곳에 있음 | 크게 줄어듦 |
| 걸린 시간 | 1~2초 | 약 2분 (첫 실행, 모델 다운로드 포함) |

### 설치

> Apple Silicon Mac 전용입니다. Intel Mac에서는 설치되지 않습니다.

1. 먼저 `실행.command`를 한 번 실행해 기본 설치를 마칩니다.
2. **`고정밀모드 설치.command`** 를 더블클릭합니다. (보안 경고가 뜨면 [처음 실행](#3-처음-실행)과 같은 방법으로 허용)
3. 수 분 기다리면 `설치 완료` 가 표시됩니다.

### 사용

화면에서 **고정밀 모드 (느림)** 를 체크하고 텍스트 추출을 누릅니다.

- **첫 사용 시** 음성 인식 모델(약 1.6GB)을 내려받으므로 더 오래 걸립니다.
- 처리 시간은 영상 길이에 비례합니다. 진행 중에는 버튼에 "받아쓰는 중"이 표시됩니다.
- 언어는 **언어** 선택의 첫 번째 언어로 받아씁니다. (예: "한국어 우선" → 한국어로 인식)

## 터미널에서 사용하기 (고급)

폴더 안에서 터미널을 열고:

```bash
.venv/bin/python yt_transcript.py "<유튜브 링크>"                  # 화면에 출력
.venv/bin/python yt_transcript.py "<링크>" -o 결과.txt              # 파일로 저장
.venv/bin/python yt_transcript.py "<링크>" --timestamps             # 시간 표시
.venv/bin/python yt_transcript.py "<링크>" --lang en,ko             # 언어 우선순위
.venv/bin/python yt_transcript.py "<링크>" --whisper                # 고정밀 모드
.venv/bin/python yt_transcript.py --help                            # 전체 옵션
```

`.venv`는 `실행.command`를 처음 실행할 때 만들어지는 이 프로그램 전용 Python 환경입니다.

## 문제 해결

<details>
<summary><b>"확인되지 않은 개발자" 경고로 열리지 않아요</b></summary>

[처음 실행](#3-처음-실행)의 2번을 따라 허용하세요.
그래도 안 되면 터미널에서 아래 명령어로 다운로드 표시를 지울 수 있습니다. (경로는 실제 폴더 위치로 바꾸세요)

```bash
xattr -dr com.apple.quarantine ~/Documents/youtube-transcript-extractor
```
</details>

<details>
<summary><b>"권한이 없기 때문에 열 수 없습니다"라고 나와요</b></summary>

실행 권한이 빠진 경우입니다. 터미널에서:

```bash
cd ~/Documents/youtube-transcript-extractor   # 실제 폴더 위치로
chmod +x *.command
```
</details>

<details>
<summary><b>"Python 3.9 이상이 필요합니다"라고 나와요</b></summary>

[1. Python 준비](#1-python-준비)를 진행한 뒤 다시 실행하세요.
</details>

<details>
<summary><b>"설치에 실패했습니다"라고 나와요</b></summary>

인터넷 연결을 확인하고 `실행.command`를 다시 실행하세요. 실패하면 자동으로 정리되므로 그냥 다시 실행하면 됩니다.
회사·학교 네트워크에서는 방화벽 때문에 설치가 막힐 수 있습니다.
</details>

<details>
<summary><b>브라우저가 자동으로 열리지 않아요</b></summary>

터미널 창에 표시된 `실행 중: http://127.0.0.1:XXXX` 주소를 복사해 브라우저 주소창에 붙여넣으세요.
주소 끝 번호는 실행할 때마다 달라질 수 있습니다. (기본 8765, 다른 프로그램이 쓰고 있으면 빈 번호로 바뀜)
</details>

<details>
<summary><b>"이 영상에는 자막이 없습니다" / "자막이 꺼져 있습니다"</b></summary>

영상 게시자가 자막을 막아둔 경우입니다. **고정밀 모드**를 사용하면 자막 없이도 받아쓸 수 있습니다.
</details>

<details>
<summary><b>"유튜브가 요청을 차단했습니다"</b></summary>

짧은 시간에 너무 많이 요청하면 유튜브가 일시적으로 막습니다. 잠시(수십 분~몇 시간) 기다린 뒤 다시 시도하세요.
VPN을 사용 중이라면 끄고 시도해 보세요.
</details>

<details>
<summary><b>잘 되던 게 갑자기 안 돼요</b></summary>

유튜브 쪽 변경으로 자막을 가져오는 방식이 깨졌을 수 있습니다. 폴더에서 터미널을 열고 라이브러리를 업데이트하세요:

```bash
.venv/bin/pip install -U youtube-transcript-api yt-dlp
```
</details>

<details>
<summary><b>"서버에 연결할 수 없습니다"라고 나와요</b></summary>

`실행.command`로 열린 터미널 창을 닫으면 서버도 꺼집니다. `실행.command`를 다시 실행하세요.
</details>

## 업데이트 · 삭제

**업데이트**
- zip으로 받은 경우: 새 버전을 내려받아 기존 폴더를 교체하세요. (처음 실행 시 설치가 다시 진행됩니다)
- git으로 받은 경우: 폴더에서 `git pull`

**삭제**
1. 폴더를 통째로 휴지통에 버립니다.
2. 고정밀 모드를 썼다면 음성 인식 모델도 지웁니다:

   ```bash
   rm -rf ~/.cache/huggingface/hub/models--mlx-community--whisper-large-v3-turbo
   ```

## 주의 사항

- 유튜브가 공식으로 제공하는 방법이 아닌 경로로 자막을 가져옵니다. 유튜브 정책 변경에 따라 동작하지 않을 수 있습니다.
- **개인 학습·참고 용도로만 사용하세요.** 추출한 텍스트를 재배포하거나 상업적으로 이용하면 원 영상의 저작권을 침해할 수 있습니다.
- 자동 생성 자막과 음성 인식 결과에는 오류가 있을 수 있습니다. 중요한 내용은 원본 영상으로 확인하세요.
